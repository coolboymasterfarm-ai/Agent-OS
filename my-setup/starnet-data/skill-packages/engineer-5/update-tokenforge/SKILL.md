## Setup
Ensure you have Git and Node.js installed.

1. Check your tools: Ensure you have Git and Node.js installed. 2. Pull the newest code from GitHub: Fetch the latest changes from the repository. 3. Build TokenForge.exe: Run build.ps1 to generate the executable. 4. Backup the running executable: Save a copy of the current TokenForge.exe to a backup location. 5. Install the new executable: Replace the old TokenForge.exe with the newly built one. 6. Verify the update: Check that the update was successful and the application is running correctly.
